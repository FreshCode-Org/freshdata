# Contributor Recognition & Community Growth Copy

Templates and copy for recognizing open-source contributors, announcing Good First Issues, and celebrating milestones.

---

## 1. Contributor Spotlight Template (Friday Community Post)

**Platform**: LinkedIn & Twitter/X  
**Audience**: Open-source community

```text
🎉 Huge shoutout to @<contributor-handle> for their contribution to FreshData this week!

@<contributor-handle> implemented PR #<PR-number> (<PR-title>):
<Brief 1-sentence description of the improvement, e.g. "Adding support for UK postal code validation in our fieldcheck engine.">

Why this matters:
<1 sentence on user impact, e.g. "Data teams in the UK can now clean customer address tables without writing custom regex.">

Check out their work:
https://github.com/FreshCode-Org/freshdata/pull/<PR-number>

Want to get involved? We have beginner-friendly issues waiting:
https://freshcode-org.github.io/freshdata/contributing/first-contribution/
```

## 2. Weekly "Good First Issue" Roundup (Monday Post)

**Platform**: Twitter/X & Reddit /r/opensource

```text
Looking for a clean, impactful open-source Python contribution this week? 🐍

FreshData (automated tabular data cleaning for pandas & Polars) has 3 freshly scoped issues ready for contributors:

1. 🟢 Level 1 (20m): Add DuckDB Parquet recipe in examples/integrations
   Link: https://github.com/FreshCode-Org/freshdata/issues/<issue-id>

2. 🟢 Level 1 (30m): Add Unicode non-breaking space test case in tests/test_strings.py
   Link: https://github.com/FreshCode-Org/freshdata/issues/<issue-id>

3. 🟡 Level 2 (1-2h): Add German postal code regex in fieldcheck.py
   Link: https://github.com/FreshCode-Org/freshdata/issues/<issue-id>

Our First Contribution Guide walks you through setup in 15 minutes:
https://freshcode-org.github.io/freshdata/contributing/first-contribution/

Drop a comment on an issue to claim it!
```

## 3. GitHub Star Milestone Post (Contextual & Organic)

**Platform**: Twitter/X & LinkedIn  
**Guiding Principle**: Never celebrate vanity stars in isolation; connect milestones to developer adoption and real problem solving.

```text
🚀 100 developers are now using FreshData to clean pandas and Polars DataFrames!

When we launched FreshData, our thesis was simple:
Developers don't need another profiler to tell them their data is dirty. They need a tool that safely repairs it and explains what it changed.

Since launch:
- 10+ community recipes added across Polars, DuckDB, scikit-learn, and Airflow.
- Verified 0.0% false-repair rate across 100,000-row benchmark suites.
- 93% test coverage enforced on every PR.

Thank you to every developer who tried the library, filed an issue, or opened a PR.

If FreshData saved you time this week, give us a star to help other engineers discover it:
https://github.com/FreshCode-Org/freshdata
```
